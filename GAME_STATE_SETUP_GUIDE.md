# 🚀 Руководство по Запуску и Проверке

## 📝 Краткое Описание Проблемы и Решения

### 🔴 Проблема
При каждой перезагрузке страницы инициализировалась новая игра, карты перемешивались заново.

### 💚 Решение  
Включено сохранение состояния игры в `localStorage`:
- **GameStore** автоматически сохраняет игру при каждом обновлении
- **GameBoard** проверяет наличие сохраненной игры перед инициализацией новой
- **При выходе** состояние полностью очищается

### ✅ Результат
При перезагрузке страницы восстанавливается та же самая игра!

## 🔍 Отладка: Если Что-то не Работает

### ❌ Игра не восстанавливается при перезагрузке

**Проверьте:**
```javascript
// В консоли браузера:
console.log(localStorage.getItem('splendor-game-state'))

// Должно вывести JSON объект, если есть сохраненная игра
```

**Возможные причины:**
1. Включен режим **Inognito** (выключает localStorage)
2. **Кэш переполнен** (localStorage > 5MB)
3. **Браузер очистил данные**

**Решение:**
```javascript
// Выключите режим Inognito и попробуйте снова
// Или откройте в новом окне обычного браузера
```

### ❌ Карты меняются при перезагрузке

**Проверьте логи консоли:**
```
// НЕПРАВИЛЬНО:
✅ Игра загружена из localStorage
🎮 Инициализируем новую игру (первый вход)  ← Это проблема!

// ПРАВИЛЬНО:
✅ Игра загружена из localStorage
✅ Игра уже загружена из localStorage, ID: 123  ← Должно быть это
```

**Если видите "Инициализируем новую игру":**
→ localStorage не сохраняет данные
→ Режим Inognito включен или кэш отключен

### ❌ localStorage полная

**Посчитайте размер:**
```javascript
JSON.stringify(localStorage).length  // в байтах
```

**Если > 5MB:**
```javascript
localStorage.clear()  // Очистить ВСЁ
// Перезагрузить браузер
```

## 📞 Часто Задаваемые Вопросы

### Q: Где сохраняется игра?
**A:** В `localStorage` браузера, под ключом `splendor-game-state`

### Q: Почему localStorage а не БД?
**A:** localStorage для кэширования, БД на сервере имеет истину. При получении `game_state` с сервера localStorage обновляется.

### Q: Что будет при очистке кэша браузера?
**A:** localStorage очистится, при следующем входе создастся новая игра.

### Q: Работает ли в режиме Inognito?
**A:** Частично - localStorage может быть отключен. Игра будет работать, но не будет сохраняться.

### Q: Что если localStorage переполнена?
**A:** Сохранение не произойдет. Нужно очистить кэш или удалить старые данные.
