# ✅ Чек-Лист Тестирования Сохранения Состояния Игры

## 🧪 Тест 1: Новая игра при первом входе

### Шаги:
1. **Откройте браузер в новом окне (Inognito режим)**
2. **Перейдите в GameBoard**
3. **Смотрите консоль браузера (F12)**

### Ожидаемые логи:
```
✅ Игра загружена из localStorage
🎮 Инициализируем новую игру (первый вход)
💾 Игра сохранена в localStorage, ID: 123
```

### Проверка localStorage:
1. **DevTools → Application → Local Storage**
2. **Найдите ключ `splendor-game-state`**
3. **Должен содержать JSON с полной игрой**

---

## 🔄 Тест 2: Восстановление при перезагрузке

### Шаги:
1. **В GameBoard запомните ID игры** (есть в логах)
2. **Запомните расположение карт** (скриншот или запись)
3. **Нажмите F5** (перезагрузка страницы)
4. **Смотрите консоль**

### Ожидаемые логи:
```
✅ Игра загружена из localStorage
✅ Игра уже загружена из localStorage, ID: 123
```

### Проверка:
- ✅ ID игры тот же
- ✅ Карты на тех же местах
- ✅ Жетоны в том же количестве
- ✅ Игроки те же

---

## 🗑️ Тест 3: Выход из комнаты очищает состояние

### Шаги:
1. **В GameBoard нажмите "Покинуть комнату"**
2. **Смотрите консоль браузера**

### Ожидаемые логи:
```
🚪 Выходим из комнаты, очищаем состояние
🗑️ Игра удалена из localStorage
```

### Проверка localStorage:
1. **DevTools → Application → Local Storage**
2. **Найдите ключ `splendor-game-state`**
3. **Должен быть ПУСТО или отсутствовать**

---

### Шаги:

2. **Создайте новую комнату и войдите в GameBoard**

### Ожидаемые логи:

🎮 Инициализируем новую игру (первый вход)
💾 Игра сохранена в localStorage, ID: 456
```

### Проверка:

- ✅ Карты другие (новая инициализация)

3. **Нажмите "Начать игру"**

🎮 START_GAME: gameId=123, playerId=user1
✅ Игра создана. Players: 0, Game ID: 123
💾 Игра сохранена в games Map для ID=123
✅ broadcastGame: отправлена игра 123 для 1 клиентов
```

## 🧯 Тест 7: Обработка Ошибок

### Шаги:
1. **Откройте DevTools консоль**
2. **Выполните:**
   ```javascript
   localStorage.setItem('splendor-game-state', 'invalid json');
   ```
3. **Перезагрузите страницу (F5)**

### Ожидаемые логи:
```
Failed to load game state
🎮 Инициализируем новую игру (первый вход)
```

### Проверка:
- ✅ Ошибка обработана корректно
- ✅ Создана новая игра вместо крэша
- ✅ Пользователь может продолжать

---

## 📊 Тест 8: Размер LocalStorage

### Шаги:
1. **Откройте DevTools → Application → Local Storage**
2. **Найдите `splendor-game-state`**
3. **Скопируйте и посчитайте размер:**

## 🔧 Отладка

### Если localStorage не сохраняется:
```javascript
// В консоли браузера
console.log(localStorage.getItem('splendor-game-state'));
// Если null - проверьте что setGame() вызывается

// Принудительное сохранение:
gameStore.saveGame(gameStore.game);
```

### Если localStorage заполняется дублями:
```javascript
// Очистите:
localStorage.clear();
// Перезагрузите страницу
```

### Если игра не восстанавливается:
```javascript
// Проверьте конструктор GameStore:
console.log(gameStore.loadGame());
// Должен вернуть объект или null

// Если JSON повреждена:
localStorage.removeItem('splendor-game-state');
```
